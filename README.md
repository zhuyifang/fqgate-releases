# FQGATE

FQGate 是免费的本地量化交易网关。它运行在你的电脑上，让 AI 助手能够查询行情和账户数据；在你主动开启相应功能后，也可以使用委托下单、资金划转等能力。

## 下载 Windows 版

首个 Windows 发行包正在准备中。发布完成后，本页会提供直接下载入口。

> 当前程序还没有数字签名，Windows 可能显示安全提示。请只从本仓库的发行页面下载；如需确认文件是否完整，可以核对页面公布的 SHA-256 文件校验值。

## 使用方法

1. 下载并解压 Windows 安装包，运行 `FQGate.exe`。
2. 首次启动时阅读并确认风险声明，再按需开启账户查询、委托下单或资金划转权限。
3. 打开下方的 AI 插件项目，按照首页说明完成安装并连接这台电脑上的 FQGate。
